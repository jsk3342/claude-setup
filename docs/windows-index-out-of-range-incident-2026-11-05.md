# 윈도우 설치 중단 `인덱스가 배열 범위를 벗어났습니다` 기록

2026-11-05 정리. 고객 정보는 넣지 않았다.

## 증상

Windows PowerShell 5.1 한글 콘솔에서 설치가 `IndexOutOfRangeException`으로 끊겼다. 오류는 `Write-Host` 또는 `Invoke-WebRequest` 줄에서 났다.

## 원인

진행 막대와 구분선 `━`가 함께 있을 때 난다. 한글 콘솔은 `━`를 2칸으로 세고, 진행 막대가 화면을 저장하다 범위를 넘는다. 설치기의 `$ErrorActionPreference = "Stop"` 때문에 표시 오류가 설치 전체를 끊었다.

호스티드 윈도우 러너는 `━`를 1칸으로 세어 재현되지 않는다. 코드페이지를 949로 바꿔도 같다.

## 실제 한글 윈도우 시험 (2026-11-05)

Windows 11 한글판, 코드페이지 949, 설치 없이 임시 콘솔 창으로 돌렸다. `━`=2칸을 실측했다.

| 시험 | 폭 69, 71, 79 | 폭 120 |
|---|---|---|
| 수정 전 `Write-Step`(`9fc2846`) | 끊김 | 통과 |
| 현재 `Write-Step` | 통과 | 통과 |
| `━` 화면 + 진행 막대 | 끊김 | 통과 |
| 현재 화면 + 진행 막대를 강제로 표시 | 통과 | 통과 |
| `━` 화면·현재 화면·한글 화면 + `irm` | 통과 | 통과 |
| 한글 화면 + 진행 막대를 켠 다운로드 | 통과 | 통과 |

시험 스크립트: `jsk3342/win-iterm2` 커밋 `8c008d7`, `c1650b8`의 `observe/`.

## 조치

- `claude-setup`: 진행 막대를 끄고 구분선을 ASCII로 바꿈(`55ba587`). CI가 `Write-Progress`와 `━`를 막음.
- `win-iterm2`: 예방으로 진행 막대를 끄고(`fc5254e`) 같은 검사를 CI에 넣음(`9e3e074`). 이 설치기가 같은 오류로 끊긴다는 증거는 찾지 못했다.
- 공식 설치기와 Scoop 설치 스크립트도 다운로드 때 진행 막대를 끈다(원문 확인).
- 끊기면 `설치 실패 보고` 칸이 나온다(`10c8ef3`).

## 미확인

- 창 폭 116칸 이상에서 `Invoke-WebRequest`로 끊긴 2026-10-23 건의 원인. 지금은 그 다운로드도 진행 막대가 꺼져 있다.
- 시험한 네 폭 밖의 조건, 다른 PC.
- `claude-setup`의 CI는 `main` 푸시에서 자동으로 돌지 않는다. 수동 실행이나 `verify/**` 브랜치에서 돌린다.

## 다시 나오면

실패 보고의 단계, 오류, 코드페이지, 창 폭을 먼저 본다. 그다음 위 시험 스크립트로 같은 폭을 재현한다. CI 통과만으로 이 오류가 없다고 판단하지 않는다.

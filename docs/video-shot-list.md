진행·완료·모드 이미지는 브라우저에서 출처 있는 로그를 재생한 화면이다. 원본 OS 터미널 촬영이라고 소개하지 않는다. 모드의 17%·25%·37%는 테스트 입력이며 실제 계정 수치로 소개하지 않는다. 2분 22초는 해당 CI 실행 시간이며 일반 컴퓨터 설치 시간 약속이 아니다.

HTML·텍스트 원본은 [capture-source](capture-source/)에 있다. 영상 편집 시 캡처를 그대로 쓰거나, 그 원본을 띄워 필요한 부분을 확대할 수 있다. 같은 내용의 원본 OS 촬영을 확보하면 실제 조작 장면은 그 영상으로 대체한다.

## 실제로 더 촬영할 순서

| 순서 | 촬영할 행동 | 초보자의 질문을 넣을 위치 |
|---|---|---|
| 1 | 실제 뉴스 결과 짧은 미리보기 | “깔고 나서 뭘 할 수 있죠?” |
| 2 | 내 OS 경로·계정 조건 안내 | “내 노트북으로 되나요?” |
| 3 | 기본 터미널 / PowerShell 열기 | “명령어를 어디에 넣어요?” |
| 4 | 설치 링크 → 복사 → 붙여넣기 → Enter | 설치 명령과 AI 대화를 화면으로 구분 |
| 5 | 실제 대기·비밀번호 입력·완료 | “멈춘 건가요?” 단계 번호와 전체 완료 구분 |
| 6 | 새 iTerm2 / Windows Terminal → `claude` | “설치했는데 어떻게 켜요?” |
| 7 | 로그인 → 필요한 권한 확인 | 선택하는 계정과 현재 승인할 작업을 그 순간에 설명 |
| 8 | “오늘 뉴스 정리해서 알려줘” → 실제 응답 | 응답이 영상과 달라도 잘못한 증거는 아님 |
| 9 | 실제 응답 뒤 모드 값 확인 | 값이 아직 없으면 0으로 꾸미지 않음 |
| 10 | 종료 → 새 창 → `claude` 재실행 | “내일도 다시 설치해요?” |

꾸미기는 별도 저장소의 선택 안내다. 자기 설정을 유지해도 기본 실습을 따라갈 수 있어야 한다. MD·스킬 제작·API·서비스 배포 설명은 필요가 생기는 후속 활용편으로 넘긴다.

실제 초보자 질문은 해당 순간에 익명으로 소개한다. 이름·프로필·계정·인증 코드·키는 공개하지 않는다. 화면이 다른 경우에는 어디까지 정상적으로 진행된 것인지 짚고, 도움받는 문서 위치를 안내한다.

## 촬영 완료 체크

- [ ] 두 OS에서 앱을 여는 위치·붙여넣기·Enter·새 창·실행을 생략하지 않았다.
- [ ] 로그인 정보와 개인 경로를 가렸다.
- [ ] 실제 뉴스 응답의 날짜·출처를 확인했다.
- [ ] 실제 계정 모드 값을 확인했다. 테스트 이미지와 구분했다.
- [ ] 껐다가 혼자 다시 켜는 행동까지 촬영했다.
- [ ] 같은 요청에 다른 응답이 나와도 실수라고 단정하지 않는 설명을 넣었다.
- [ ] 미확인 다운로드 수·설치 시간·모든 PC 성공을 홍보하지 않았다.
